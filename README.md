This project implements a data pipeline that loads, validates, cleans, and saves data. The src/data_loaders.py module loads data, while src/data_validator.py checks required columns and numeric values. The src/data_processor.py module removes duplicates, handles missing values, and detects outliers based on config/config.yaml. The src/data_output.py module saves the cleaned data, src/utils.py provides logging and input-file validation, and pipeline.py coordinates the modules. Run the pipeline using python pipeline.py --input fixtures/sample_data.csv --output output/clean.csv --config config/config.yaml --verbose; it saves the cleaned dataset to output/clean.csv, producing 92 rows and 5 columns after processing.
